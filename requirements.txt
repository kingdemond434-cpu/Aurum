# Aurum — what the LIVE DESK needs. Nothing more.
#
#   python3 -m venv .venv && . .venv/bin/activate
#   pip install -r requirements.txt
#
# PINNED, not floated. This desk's whole claim is that a result recorded in
# March can be re-derived in September; a silent minor-version bump in the
# analyst client breaks that quietly rather than loudly. Bump deliberately,
# re-run the suites, commit the new pin.
#
# WHY PANDAS IS NOT HERE. It was, and it should not have been. pandas and
# pyarrow are a parquet reader/writer used by the research path and the data
# fetchers — backtest.py, ParquetBarSource, fetch_dukascopy.py, export_mt5.py.
# The live desk gets bars from OANDA over HTTP, writes its ledger as JSONL and
# its ticks as gzipped CSV, and touches neither library. Verified by importing
# the whole live path with both blocked.
#
# That matters operationally: pyarrow is the most likely thing to fail to build
# on a small VPS, and a desk that never uses it should not be unable to start
# because of it. Research deps live in requirements-research.txt.
